### 1.3 精度预算（重写 —— 这是 v1 最大的一处记账错误）

#### 1.3.1 v1 的算法与错在哪

v1 §1.3 写：

```
误差 ≈ 频率偏差 × 同步龄期
     = 20e-6 × 0.15 s × 3e8 m/s ≈ 0.9 m   （极端）
```

自审报告 P2-2 把龄期改成代码里的 `CS_REF_MAX_AGE_DTU = 3e10`（0.47 s），得"最坏 ≈ 2.8 m"。

**两处都错，而且错在同一个地方：把「晶振的绝对频率精度」当成了「两节点之间的频率比误差」。**

TDOA 是一个**差分**量，它需要的只是"锚 A 的钟"与"锚 B 的钟"之间**比值**的准确度：

$$\Delta t_{\text{TDOA}} \;\supset\; \Delta f_{\text{ratio}} \times \Delta t_{\text{span}}$$

- 两个节点各自相对"理想频率"差 20 ppm（晶振规格）——**与 TDOA 无关**。两枚都偏 20 ppm 的芯片，对 TDOA 的贡献是 **0**。
- 真正进入误差的是 $f_A/f_B$ 这个**比值**的估计误差。而这个比值在本项目里是**实测**出来的：
  - 锚侧 `clock_sync.c` 的 `cs_rate_measure()`：`CS_RATE_WINDOW_SAMPLES = 16` 个样本 × 50 ms = **800 ms 窗口**，注释自述 **≈1 ppb**；
  - 标签侧 `fusion_tag.c` 的 `s_root_rate`：5 个 **单轮**（50 ms）比值 `d_rx/d_tx` 的**中值**。
- 把 20 ppm 当成 $\Delta f_{\text{ratio}}$，等于把一个 1 ppb 的实测值替换成 2×10⁴ ppb 的臆测值 —— **高估了约 10 000 倍**。

#### 1.3.2 重算

| 项 | 量级 | 依据 |
|---|---|---|
| 锚间频率比估计误差 $\Delta f_{\text{ratio}}$ | **1–2 ppb**（800 ms 窗口） | `clock_sync.c` 注释自述 ≈1 ppb；标签侧单轮中值约 1–2 ppb（**待 Phase 0 实测**） |
| 同步龄期（参考点年龄） | ≤ 0.47 s（`CS_REF_MAX_AGE_DTU`） | `clock_sync.h` |
| **频率比项对 TDOA 的贡献** | 2 ppb × 0.47 s × 3e8 m/s ≈ **28 cm** | 若 $\Delta f_{\text{ratio}}$ 真为 2 ppb |
| 若 $\Delta f_{\text{ratio}}$ 实为 0.2 ppb | ≈ **2.8 cm** | 800 ms 窗口的乐观值 |
| **DS-TWR corr 龄期项** | **未量化 —— 主导项** | corr 每超周期刷新，但**帧内不携带测量龄期**（见 §5.1.3） |
| 天线延迟 / TX 延迟标定残差 | 未量化 —— **主导项** | 逐锚常数偏置，直接进 TDOA |
| 多径 / NLOS | 未量化 —— **主导项** | 粮库环境典型 10–50 cm |

**结论**：L2 的 30~50 cm 目标**是对的，但理由不是 v1 给的那个**。真实误差大头是
**① DS-TWR corr 的真实龄期未受控、② 天线/TX 延迟未标定、③ 多径**，
**不是频率比**。因此 §9 的 Phase 顺序必须围绕这三项重排 —— 这也解释了为什么 v1 "Phase 1 换测量域" 会**同时**把 ②③ 留在原地而把 ① 的唯一替代品拆掉。

> **Phase 0 的第一任务就是量清楚这张表**：每锚的 corr 龄期、TX 延迟残差、频率比残差各占多少 cm。

## 3. 测量域的物理约束（v2 新增 —— 本轮最重要的一节）

> 这一节是 v1 与自审报告**都没有判对**的地方，也是 v2 与 v1 分歧最大的地方。

### 3.1 单向链路上的「时钟偏置」与「传播时延」不可分离

设锚 A 在 $t_A$ 时刻发射，Tag 在 $t_r$ 时刻收到。则

$$t_r = t_A + \frac{d_A}{c} + \underbrace{(\theta_A - \theta_{\text{tag}})}_{\text{钟偏置}}$$

单向观测里，$d_A/c$ 与钟偏置**以和的形式出现**，任何仅基于该帧的映射都**无法**把它们分开。

`clock_sync` 的参考式正是这个和：

```c
/* clock_sync.c */
if (s->update_count == 0) { s->ref_tx = tx_remote; s->ref_rx = rx_local; }
s->ref_rx += s->rc_alpha * ((double)rx_local - pred);
s->offset_dtu = (double)s->ref_rx - s->factor * (double)s->ref_tx;
```

即 $M_A(t) = \text{ref\_rx}_A + \text{factor}_A \cdot (t - \text{ref\_tx}_A)$。
对**参考帧自身**恒有 $M_A(\text{ref\_tx}_A) = \text{ref\_rx}_A$ —— 而参考帧真实的 $M_A(\text{ref\_tx}_A)$ 应当是 $\text{ref\_rx}_A - d_A/c$。

**结论：参考对的选取，把该参考帧的传播时延 $d_A/c$ 整个吸收进了映射的常数项。**

### 3.2 per-anchor 映射的三种结局

设参考帧时刻为 $t_{ref,A}$，当前帧时刻为 $t_A$。因为参考对被持续刷新：

$$\text{rx}_A - M_A(\text{tx}_{A,\text{raw}}) \;=\; \frac{d_A(t_A) - d_A(t_{ref,A})}{c} \;=\; \Delta d_A$$

即**路径长度的变化量**，而不是路径长度本身。代入 TDOA：

$$\text{TDoA}(A,B) \;=\; \underbrace{\big(\Delta d_A - \Delta d_B\big)}_{\text{参考龄期内的路径变化}} \;\ne\; \underbrace{\frac{d_A - d_B}{c}}_{\text{我们要的}}$$

三种结局：

| 参考更新方式 | $\text{TDoA}$ 等于 | 后果 |
|---|---|---|
| **每帧各自刷新**（本项目现状） | $\Delta d_A - \Delta d_B$，参考龄期 ≤ 1 帧 → **≈ 0** | **TDOA 恒为 0 → 求解器无约束 → 输出恒等于锚质心。v1 要修的症状被精确复现。** |
| 所有锚**共享同一参考时刻** $t_{ref}$ | $\text{TDoA}(t_{now}) - \text{TDoA}(t_{ref})$ | **差分定位**：给出的是**相对 $t_{ref}$ 时刻的位移**。要还原绝对位置，必须已知 $t_{ref}$ 时刻标签的位置。 |
| 锚↔锚有**往返**测量（ToF 中继 / DS-TWR） | 真正的 $\frac{d_A-d_B}{c}$ | 这就是 bitcraze TDoA3 的做法，也是 §3.3 的唯一可行路 |

### 3.3 绝对 TDOA 只有三条路

| 路径 | 机制 | 本项目现状 |
|---|---|---|
| **A. 公共时基** | 所有锚的发射时刻被放在**同一条时间轴**上；Tag 只需在同一轴上做差 | ✅ **在用**：Root 栅格 + DS-TWR corr |
| **B. 往返测量** | 锚↔锚测出往返时延，传播时延不再被吸收 | ⚠️ **在用但只覆盖 Root↔子站**：DS-TWR corr |
| **C. 有线公共参考** | PPS / 公共 38.4 MHz | ❌ 无（§5.6 预留接口） |

**v1 §4.1 "彻底放弃 Root 绝对网格" = 同时关掉 A 与 B，只剩一条退化路。**

### 3.4 本项目现状走的是哪条

现状是 **A + B 的组合**，且耦合得很紧：

```
Root（level 0）
  ├─ 栅格原点 s_root_grid_base（Root 钟，一次设定）
  ├─ 每轮向全网广播 DS-TWR corr（各子站的往返传播时延）
  └─ slot 表（roster→slot 确定性分配）

子站（level ≥ 1）
  ├─ base_origin = rx_local(root beacon) − s_twr_corr_dtu − s_tx_delay_dtu
  │     ↑ 用 corr 把"Root↔我"的传播时延扣掉，使自己的栅格与 Root 的栅格同轴
  ├─ period_local = period × f   （f = 子站钟 vs Root 钟，实测）
  └─ 每轮发射，帧内带 tx_ts40（计划栅格时刻 + δ）与 tx_err（离格量）

Tag
  └─ toa_eq = rx_local − slot × (DTU_PER_SLOT × s_root_rate) − tx_err
        └─ 两锚相减 ⇒ 公共时基下的 TDOA
```

**这条路的误差来源（全部进 TDOA）：**

| 来源 | 量级 | 状态 |
|---|---|---|
| 频率比误差 × 龄期 | 1–2 ppb × 0.47 s ≈ 3–28 cm | 可实测（U6） |
| **DS-TWR corr 陈旧**（R11） | **未受控** | **待修（§5.1.3）** |
| **corr 半程假设的常数偏置**（R12） | 逐链路不同 | **待标定（§5.5.2）** |
| **子站 TX 延迟标定残差** | 逐锚常数 | **待标定（§5.5.2）** |
| **天线延迟** | 逐锚常数 | **待标定（§5.5.2）** |
| Root↔子站链路多径 | 10–50 cm | 结构性 |

### 3.5 结论对 §9 的约束

1. **保留 Root 栅格。** 它不是"要拆的旧包袱"，它是 §3.3 里的路径 A。
2. **Phase 1 的第一位不是换测量域，而是把路径 A 的三个漏洞补上**：corr 真实龄期（R11）、corr 偏置（R12）、龄期上报。
3. **per-anchor 映射按 §3.2 的第二种结局实现**（共享参考时刻的差分定位），作为**科研/诊断通道**，**不进入产品定位路径**。它的价值在于：它能在一个**没有 Root** 的场景下给出**位移**，这是 Root 栅格给不了的；而且它的实现成本低，可以作为 §9 Phase 2 的 A/B 对照。
4. **任何"绝对 TDOA"的声称，都必须能回答"传播时延在哪一步被测出来的"。** 答案只能来自路径 B 或 C。

### 4.3 目标数据流

```
Anchor（Root + Child 同一二进制）

Tag（sniffer + 本地解算）
  ├─ 收帧 → rx_local（Tag 钟）
  ├─ 公共时基换算：toa_eq = rx_local − slot×slot_eff − tx_err

  ├─ 鲁棒平均：中值 + Huber
```

## 5. 核心机制（修订）

### 5.1 公共时基：保留 Root 栅格，强化 DS-TWR corr

#### 5.1.1 不动的部分

Root 栅格、roster→slot 确定性分配、delayed TX、`tx_ts40`/`tx_err` 语义 —— **全部保留**。Phase 0 之前不动任何行为。

#### 5.1.2 corr 的角色要说清楚

`FUNC_TWR_CORR (0xE7)` 广播里每条 entry 是 `rank(u16) + corr_dtu(u16)`（`DL_TWR_CORR_ENTRY_LEN = 4`）。
`corr_dtu` 是 **Root↔该子站的往返传播时延**（子站钟单位），子站用它构造 `base_origin`：

```c
g_tdma_ref.base_origin = rx_local(root beacon) − s_twr_corr_dtu − s_tx_delay_dtu;
```

**它是"路径 A（公共时基）"与"路径 B（往返测量）"的接合点** —— 整个方案里唯一一处传播时延被真正测出来的地方。v1 差点把它拆掉。

#### 5.1.3 corr 必须携带测量龄期（修 R11，对应 Phase 1）

**问题**：子站每收到一次广播就刷新 `s_twr_corr_cycle = g_tdma_ref.root_cycle_id;`，
但**广播里的 `corr_dtu` 值可能是 Root 很久以前测的**（Root↔子站的往返测量可能早就断了，只剩 Root→子站的单向广播还在）。
于是子站认为"我的 corr 是新鲜的"，而实际上它的栅格放置误差在**无人察觉**地增长。
更糟：`TWR_CORR_STALE` 这个守卫**因此实际上从不触发**（`corr_valid` 永不过期）。

**修法（协议改动，最小面）**：

| 项 | 现状 | 目标 |
|---|---|---|
| entry 布局 | `rank(u16) + corr_dtu(u16)`（4 B） | `rank(u16) + corr_dtu(u16) + meas_cycle(u16) + corr_count(u16)`（8 B） |
| 帧长 | `12 + 8×4 = 44` B | `12 + 8×8 = 76` B（< DW3210 载荷上限，且需按 §6.3 补尾部 pad） |
| `meas_cycle` 语义 | — | **该条 corr 被 Root 实际测得时所在的 Root cycle id** |
| 子站行为 | 收到即刷新 `s_twr_corr_cycle` | 改为 `s_twr_corr_meas_cycle = meas_cycle`；**龄期 = 当前 cycle − meas_cycle**，超过 `DL_TWR_CORR_MAX_AGE_CYCLES` 即置 `TWR_CORR_STALE` 并让出 slot |

**验收**：`GR,<rank>,<corr_age_cycle>,<corr_dtu_cm>,<count>` 1 Hz 打印；人为拔掉 Root↔子站的往返测量 3 s 后，子站必须**主动退位**（`slot = 255`），而不是带着陈旧 corr 继续发。

#### 5.1.4 链路质量门控（对应 Phase 1）

corr 的质量目前只有一个 `corr_count`（累计次数）。需要：
- `corr_count` 的**增量**（最近 N 轮的更新率）→ 太慢说明链路在退化；
- `corr_dtu` 的**抖动**（最近 N 轮的极差）→ 抖动大说明多径严重，该链路的 corr 不可信；
- 两者任一越限 → 该子站的放置标记为"低质量"，其帧进 TDOA 时降权或剔除。

### 5.2 per-anchor 映射：降级为差分定位（不是绝对定位）

按 §3.2，per-anchor 映射**可以**实现，但只有一种有意义的形态：

> **所有锚共享同一个参考时刻 $t_{ref}$**，各锚用自己的参考对构造映射，
> 于是 $\text{TDoA}_{\text{computed}} = \text{TDoA}(t_{now}) - \text{TDoA}(t_{ref})$。

配套要求：
1. $t_{ref}$ 必须是**所有锚共用**的同一时刻（当前做不到：每锚各自刷新参考 → 退化成 §3.2 第一行）；
2. 必须已知标签在 $t_{ref}$ 时刻的位置 $\mathbf{p}_{ref}$，否则只能给出位移；
3. 输出必须打上 `DISPLACEMENT` 标志位，**禁止**被上位机/机器人当作绝对坐标使用。

**Phase 2 的做法**：实现为**编译期开关的第二条 Tag 路径**，与 slot 路径 A/B 对比，**默认关闭**。
对比指标只有一条：**残差方差**（P1-7 的相对判据），而不是绝对精度。

**预期结果（v2 的预判）**：按 §3.2 第一行，这条路径的 TDOA 会 ≈ 0，输出复现"恒等于质心"。
**这个阴性结果本身就是 Phase 2 的价值** —— 它把 §3.1–§3.3 的论证变成**实测证据**，从而为"保留 Root 栅格"（Phase 7 是否需要去中心化）提供裁决依据。

### 5.3 调度：保留 roster→slot 确定性分配

v1 §4.5 的伪随机相位**删除**，理由（P1-1 + 本轮补充）：

| 问题 | 数字 |
|---|---|
| 相位定义在 100 ms 超帧，但每锚每 **50 ms** 发一帧 | 同一相位桶内**每帧都撞** |
| 8 相位 × 12.5 ms 间隔，落在 50 ms 轮内只有 **4 个不同相位**（0/12.5/25/37.5，mod 50 折叠） | 8 锚 → **每相位 2 锚，必然同槽** |
| ±5 ms 随机抖动 | 12.5 ms − 5 − 5 = 2.5 ms < 一个 6.25 ms 槽 → **跨桶也撞** |

**保留**：`tdma_build_table_from_roster()` 的 roster→slot 确定性分配（`fusion_anchor.c`）。
**保留**：Root 掉线时的 ALOHA 兜底。
**可选改进（Phase 3，非必须）**：slot 分配时让**空间相邻**的锚拿到**相邻**的 slot。
注意：这只影响**局部精度**（决定局部精度的那一对锚的 slot 序号差变小），
**不改变误差的极值与 RMS**（残差 $\Delta = (\text{slot}_k - \text{slot}_j)\cdot S\cdot \Delta f$ 只取决于槽序号差，与谁占哪个槽无关）。
上位机现有的"按到 Root 距离排序"等选项已经能实现这一点，**只需订正其注释里的量级错误**（§9 Phase 3）。

### 5.4 时钟层：分离噪声底与速率偏置（修正 P0-5）

**先纠正 P0-5 的事实错误**：`CS_FACTOR_CLAMP` 不是"接受带宽"，是**每次更新的校正步长上限**：

```c
/* clock_sync.c */
double clamp = (warmup || step_ok) ? CS_FACTOR_CLAMP_WARMUP : CS_FACTOR_CLAMP;
double applied = innovation;
if (applied >  clamp) applied =  clamp;
if (applied < -clamp) applied = -clamp;
s->factor += K * applied;
```

且**时间戳速率优先于 CFO**（`from_ts ? factor_ts : factor_cfo`），稳态下走的是 800 ms 窗口的时间戳速率（≈1 ppb），CFO 只在 warm-up 期垫底。

所以：
- 自审报告 P0-5 的"因子被钳死在 0，永不收敛"**不成立**；
- 自审报告引用的实测 "cfo_raw=14 → 1.000214" 是 **208 ppb**，不是 200 ppm（差 1000 倍）；
- 收紧到 30 ppb 的真实后果是**收敛慢 67 倍**，在有 `step_ok` 逃生阀的情况下不会锁死，但**也没有任何精度收益**（稳态创新量本来就 ~1 ppb）。

**v2 的裁定**：

| 项 | 裁定 |
|---|---|
| `CS_FACTOR_CLAMP` | **不动**（2e-6）。它约束的是步长，不是精度 |
| 真正的目标 | **把"频率比估计误差"从 1–2 ppb 压到 0.2 ppb 量级**，即 §1.3 表里 28 cm → 3 cm 的那一格 |
| 手段 | ① 锚侧窗口已是 800 ms/16 样本；② **标签侧的 `s_root_rate` 是 5 个单轮比值的中值，窗口太短** —— 这是弱环，Phase 1 把它拉长到与锚侧同量级 |
| 门限分档 | 保留自审报告 P0-5 的**分档思路**，但**进入判据改为残差统计**（自审报告已指出这一点，v2 明确写死）：只有当"长窗口均值 vs 单轮估计"的差值 σ 降到目标档位以下，才允许收紧该档 |
| CFO 的正确用法 | CFO 只用于 **warm-up 快速起步**与**离群检测**，不参与稳态速率 |

### 5.5 标定与输出（Phase 5）

#### 5.5.1 `tx_ts40` / `tx_err` 的语义，一次定死（裁定 P1-5）

现状（`fusion_anchor.c`）：

```c
pack_40bit_ts(&pkt[DL_TS_TX_TS_IDX], dx_time_programmed(scheduled_tx) + s_tx_delay_dtu);
```

⇒ `tx_ts40` = **计划栅格时刻 + 已标定 TX 延迟 δ**，并打 `DL_TS_FLAG_TX_TS_PRECISE`。
⇒ `tx_err` = **实际出发 − 名义栅格槽**（含 DX_TIME 256-DTU 截断误差）。

**裁定**：

| 字段 | 语义 | 参与 TDOA 计算？ |
|---|---|---|
| `tx_ts40` | 发送方钟域的**本次实际发射时刻**（已含 δ 与栅格） | **是**（经公共时基换算） |
| `tx_err` | 相对名义栅格槽的**离格量**，用于**离格检测与诊断** | **否**（仅诊断） |

**禁止**再出现 `TX = M(tx_raw) + tx_err` 这种重复计入。
现有 Tag 侧 `toa_eq = rx_local − slot×slot_eff − tx_err` 中扣 `tx_err` 的做法，**在 `tx_ts40` 已含 δ 的前提下要重新核对**（`tx_ts40` 是绝对时刻，而 `tx_err` 是相对"名义槽"的量，两者基准不同）——这是 Phase 0 的**符号实测校验**项（U2 的裁定版）。

#### 5.5.2 必须标定的三个常数

| 常数 | 标定方法 | 影响 |
|---|---|---|
| 每锚 **TX 延迟** δ | 两锚背靠背测距，残差法 | 逐锚常数偏置，直接进 TDOA |
| 每锚 **天线延迟** | 同上（收发各一半） | 逐锚常数偏置 |
| 每链路 **corr 半程不对称**（R12） | 双向测距对比 | 逐链路常数偏置 |

标定结果应下发并随帧广播（§6.2）。

#### 5.5.3 输出与质量

现有质量语义已统一（0..1000，越大越好；65535 = 无解），`Z_VALID / SOLVE_VALID / 3D_SOLVED / DEGRADED` 标志齐备。
本轮**不改质量语义**，只做两件事：
1. 把 `n_inlier` 与 `rms` 一并纳入 Q（已在 `tdoa_solver.c` 实现）；
2. **新增 `DISPLACEMENT` 标志位**（§5.2），当输出是位移而非绝对坐标时置位。

### 5.6 预留：公共参考接口

`flags` bit 预留 `COMMON_REF`。若后续接入公共 38.4 MHz / PPS：
- Anchor 上报 `common_ref_valid`；
- Tag 侧在 `factor_A` 上叠加公共参考项；
- 频率比误差可从 ~1 ppb 压到 1–3 ppb 甚至更低。

这是**不改硬件前提下**通往 20 cm 的唯一路径，v1 §4.8 的判断成立，保留。

### 6.3 帧尾 pad 规则（不可破）

DW3210 通过 SPI 读帧时**最后 2 字节会被破坏**。因此：
- 每帧的**最后 2 字节必须是吸收 pad**（现有 `0xCC 0xDD`）；
- 所有 `frame_len` 检查是**下限**（`DL_TIMESYNC_MIN_LEN 63` < `DL_TIMESYNC_LEN 67`）；
- §5.1.3 扩宽 `FUNC_TWR_CORR` 后，**必须补尾部 pad**，且 `DL_TWR_CORR_MIN_LEN` 同步下调。

## 7. 上位机与网关

### 7.1 功能清单

| 序 | 功能 | 状态 | 缺口 |
|---|---|---|---|
| 1 | 显示在线锚/标签 | ✅ 已有 | — |
| 2 | 配置锚坐标 | ⚠️ 部分 | 锚侧坐标 **RAM-only**，重启丢失（R9）。受 Keil 32 KB 上限阻塞 |
| 3 | 选站组网 | ✅ 已有（`0xE8` + roster） | **不是新建功能**（P1-2）；缺的是"上槽成员数"统计 |
| 4 | find 功能去冲突 | ⚠️ | 需 token 化（§7.3） |
| 5 | 地图 / 轨迹 / 质量 | ✅ 已有 | 需加 `DISPLACEMENT` 标志的显示区分 |

### 7.2 组网：现状已具备，缺口是什么（P1-2 修正）

v1 §4.4 提出"取消运行时选举 + 上位机下发 roster + Type C 组网帧 + 组网状态机" ——
**这些代码里已经全有了**：

| v1 提的新东西 | 现状 |
|---|---|
| roster 由上位机下发 | ✅ `FUNC_NETWORK_START (0xE8)` + `roster` 字段 |
| 锚侧 roster 存储 | ✅ `fusion_anchor.c` `s_roster[]` |
| slot 表由 roster 构建 | ✅ `tdma_build_table_from_roster()` |
| 组网状态机 | ✅ `NET_IDLE / STARTING / WAIT / RUNNING` |
| 在线发现 | ✅ `FUNC_ANCHOR_DISCOVERY (0xEC)` |

**v2 裁定**：Phase 2 **不新建组网帧、不新建状态机**。
若按 v1 实施，会出现"0xC1 组网帧 vs 现有 0xE8"**两套并行协议**，网关/上位机双协议冲突。

**真正的缺口只有两个**：
1. **上槽成员数**（`slot != 255`）与"回过话的成员数"（ACK）**分开统计**——ACK 只说明听到了广播，不说明上槽了；
2. 组网结果的判据应来自锚自己的信标（`level == 0` 或 `slot != 255`），而不是网关的 ACK 计数。

### 7.3 find 去冲突

find 命令当前被广播给所有锚 → 多个锚同时频闪。
修法：命令携带 16 bit `token` + `nonce`，锚侧比对 `find_token`；上位机逐个发（200 ms 间隔）。

### 7.4 坐标持久化

锚坐标是静态配置，应存**网关/上位机侧**：`<anchor_id, x, y, z, crc>` 记录表。
锚本体只存运行时态。**本轮不动**（受 Keil 32 KB 限制，见 §11 K5）。

## 9. 实施路线（修订主线）

```
Phase 0  黄金台架 + TDOA_RAW / 符号校验 / 时钟残差统计（不动任何行为）
```

## 14. 附录 B：v2 新增（自审报告未覆盖）

### 14.1 §3 的物理约束（最重要）

自审报告在"经复核成立"里写：

> "§4.6.1 的 per-anchor 映射数学成立 …… 同一帧的 (ref_tx, ref_rx) 参考对自动消除该锚常数钟偏 —— 不必再引入 ToF 才能消除常数偏置"

**前半句对，后半句推错了方向。** 参考对消除的是**钟偏置**，但它**同时把传播时延吸收进了同一个常数项**（§3.1）。而 TDOA 需要的恰恰是传播时延之差。

⇒ 自审报告自己已经察觉到的矛盾（"传播差不会自动对消"）比它给出的结论更严重：**不是"残余误差偏置"，而是"整条路径给不出绝对量"**。

自审报告提出的折中（"per-anchor 映射降级为无 Root 时的降级模式"）**也不成立**：§3.2 第一行表明它会输出**恒等于质心**的退化解，比"无解"更危险。

### 14.2 自审报告的两处量级错误

| 位置 | 报告原文 | 正确值 | 影响 |
|---|---|---|---|
| P0-5 | "瞬时速率偏差量级 **~200 ppm**" | **208 ppb**（`cfo_raw=14` → 14/2²⁶） | "差 3 个量级" 实为差 ~7 倍；且该常数的**机制**理解也错（见 §5.4） |
| P1-7 | "5 cm 在 50 ms 龄期下要求速率误差 **< 0.6 ppm**" | **≈3.3 ppb**（按 0.47 s 龄期为 ≈0.35 ppb） | 结论不变（5 cm 达不到），推导差 ~180 倍 |

两处都**朝"更悲观"的方向**偏。建议后续引用该报告时按上表订正。

## 15. 附录 C：术语与"绝对 vs 位移"

| 术语 | 含义 | 允许出现在产品输出里？ |
|---|---|---|
| **绝对位置** | 标签在粮库坐标系里的坐标 | ✅ 允许（公共时基路径） |
| **位移** | 相对某个已知参考位置/参考时刻的增量 | ⚠️ 必须打 `DISPLACEMENT` 标志，上位机/机器人不得当绝对位置用 |
| **质心退化** | TDOA 全 0 或全等时的求解器输出 | ❌ 禁止（`L1 可用率` 的排除项） |
| **公共时基** | 一条所有锚发射时刻都落在其上的时间轴 | 必需（路径 A） |
| **corr** | Root↔子站的往返传播时延测量 | 路径 B 的唯一实现，是方案的**承重墙** |
